**cypher game**
Run the program to display the main menu.
Select 1 to start a new game or 2 to exit.
An encrypted word will appear on the screen.
Enter your guess to identify the original word.
You have 5 attempts to correctly decode each message.
If your guess is correct, you earn points and advance to the next level.
If your guess is incorrect, one attempt is deducted.
Type H to request a hint. Each hint consumes one attempt and deducts 10 points.
If all attempts are used, the correct answer is revealed, and the game proceeds to the next level.
